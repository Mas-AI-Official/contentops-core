# MAS-AI growth operations

Read [the operating contract](references/operating-contract.md). Execute authorized reversible work automatically. Pause only the dependent action when authentication, a real financial commitment or irreversible deletion requires it.

## Route the task

- Offers, hooks and copy: [creative rules](references/creative.md).
- Video, UGC, motion, captions and covers: installed remotion-best-practices plus [production rules](references/production.md).
- LinkedIn profiles, cleanup or two-account distribution: $mas-ai-linkedin.
- Business discovery, contacts and proposals: $mas-ai-prospecting.
- Editors and other channels: [platform registry](references/platforms.md).

Keep one registry. Do not move built-in skills or install unreviewed collections. Check actual installed library versions before applying current upstream guidance.

## Inspect before changing

Find the current checkout, active campaign, jobs and uncommitted edits. Read owner decisions, claims/brand records, budget, presenter manifest and handoff. Preserve finished exports and outstanding reviews. A technical QA pass does not close claims/disclosure findings.

Keep the old generic news autopilot stopped. Use a separate explicit campaign queue; never press global RUN. Verify exact destination actors. A mention does not publish to another account.

## Produce one shared creative spec

Record campaign ID, audience, problem, proof/source URLs, claim status, hook, script, storyboard, presenter/voice references and hashes, disclosure, motion version, cover, CTA, output presets and destination actors.

Use one canonical renderer/token source for video, stills and covers. Create three useful alternatives, choose against the brief, and avoid repeated full debates. Prefer local models for tagging, clustering and drafts after a real benchmark; use Claude for direction/final judgment and Codex for targeted implementation/review. Serialize GPU-heavy work on limited VRAM.

Use the repository's GrowthOps status, registry and durable campaign/prospecting queues when present. Read docs/GROWTHOPS.md before configuring its MCP server. A queued job is not executed. Reuse the existing CRM instead of building another.

Use the Claude Agent SDK only when unattended work adds value. Verify its current interface, filesystem skill loading, authentication, actual credit balance and per-run/global cost limits. A reported credit is not a verified balance or permission for top-ups. Separate research charges from media charges.

## Verify and monitor

Inspect final exports: speech, lip sync, identity, face/hands, caption bounds throughout animation, platform safe areas, sound, claims, disclosure and cover crops. Check final files, not only contact sheets.

Track queue age/status, failures, attempts, quotes/reservations/actual charges, actor IDs, artifact hashes, published IDs, replies, qualified enquiries and calls. Keep unknown metrics null. Reconcile an uncertain submission before retrying. Verify both destination receipts.

Return completed changes, checks, costs, real blockers and exact next actions. Never call a prompt, fixture or dry run a live installation or publication.
