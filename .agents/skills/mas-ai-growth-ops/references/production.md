# Consistent production

Lock a versioned presenter manifest: identity-reference IDs/hashes, voice provenance/model/reference hash, language/pronunciation, office/background, lighting, framing, wardrobe family and disclosure. A shared seed does not prove identity consistency.

Use approved AI-Masoud assets without requiring a camera shoot. Do not send his face/voice to a newly selected provider solely because generic production is authorized; verify destination-specific authority.

Keep one face/voice in the first series. Vary scripts, hooks, framing and cutaways. Label alternate-presenter experiments as separate series. Use truthful synthetic-media disclosures.

Use existing Remotion/FFmpeg for precise text, diagrams, product demos, logos and assembly. Extend one token source. Tie motion to information, allow reading holds, and parameterize scene duration/easing/distance.

Preserve subtitle constraints and add rendered pixel checks throughout animation: right-edge overflow, faces/eyes, platform chrome, contrast, CTA/URL wrapping and crop previews. Check speech/music balance, lip sync, identity/hands, continuity, codec/loudness and deliberate holds. Mutation-test accidental-freeze detection.

Compare generation cost per accepted asset, including discarded successful outputs, editing and minimum duration. Cheap text-to-video does not establish an equivalent motion-transfer or avatar replacement.

Use pinned official Remotion skills; verify installed package APIs before adopting newer components. Do not silently upgrade the rendering stack.
